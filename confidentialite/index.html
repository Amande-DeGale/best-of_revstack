Confidentialité et liens partenaires

Les calculateurs

Les chiffres saisis dans les calculateurs sont traités dans votre navigateur. Leur code ne transmet pas les valeurs saisies à un serveur.

Contact et demande d’audit

Le formulaire prépare un courriel dans votre messagerie. Vous devez l’envoyer pour transmettre la demande à l’adresse indiquée dans le courriel. Il n’existe pas de service d’envoi automatique derrière ce formulaire.

Hébergement et mesure d’audience

Le site est hébergé par GitHub Pages. Les pages du catalogue intègrent Cloudflare Web Analytics pour mesurer leur fréquentation. Ces fournisseurs traitent des données techniques selon leurs propres règles : confidentialité GitHub et confidentialité Cloudflare.

Liens externes et affiliation

Les liens partenaires actuellement renseignés concernent Make et Systeme.io. Si une inscription ou un achat est attribué au site selon les règles du programme, une commission peut être versée. Les éditeurs appliquent leurs propres règles de confidentialité et de suivi. Les autres liens du catalogue ne deviennent pas rémunérateurs par la seule présence d’un paramètre UTM.
